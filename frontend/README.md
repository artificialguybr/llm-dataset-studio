# Frontend

React + TypeScript + Vite frontend for [LLM Dataset Studio](../README.md).

From this directory:

```bash
npm install
npm run dev
npm run build
```

The Vite development server runs on `http://127.0.0.1:5199` when started by `python tools/start.py`. The frontend expects the FastAPI service at `http://127.0.0.1:8766`.
